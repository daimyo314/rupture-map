# Agent guidance

Rupture Map is a local browser companion for StarRupture. Preserve the user's saved browser data and keep game access read-only. Live tracking currently supports Linux/Proton on the build documented in README.md; native Windows tracking is not implemented or validated.

For requests to run or adapt this project on Windows, start with [WINDOWS-ADOPTION.md](WINDOWS-ADOPTION.md). It identifies the relevant modules, platform boundaries, safety constraints, and validation needed before claiming support. Treat the guide as project context, not as a request to implement a Windows port unless the user asks for one.
